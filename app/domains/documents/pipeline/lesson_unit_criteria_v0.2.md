# 교훈 단위 기준 v0.2

2026-11-03. [v0.1](lesson_unit_criteria_v0.1.md)에 대한 사용자 결정 3건을 반영한 버전이다.
v0.1의 출력 비노출 초안은 보존한다. **v0.2는 결과가 노출된 현재 대화의 사용자 지시를
반영한 개정이며, 별도의 출력 비노출 작성이라고 주장하지 않는다.**

## 1. 이번에 확정한 범위

| 항목 | 사용자 확정 내용 | 적용 경계 |
|---|---|---|
| 교훈 단위 | 독립 교훈당 1장. 같은 사건의 서로 다른 교훈은 여러 장으로 인정 | 모든 사건을 1장으로 묶지 않음. 사건·문단·조치 수로 카드 수를 정하지 않음 |
| 공통 근거 | 하나의 원문 문장·블록을 여러 교훈의 근거로 사용 가능 | 각각의 교훈을 실제로 지지해야 함. 같은 판단·행동을 표현만 바꾼 것은 중복 |
| 성공 관측 없는 자료 | 근거가 충분한 교훈을 정답표에 포함 | 공개 정책은 유형별 환각 측정 후 결정. 정답표 포함을 공개 승인으로 해석하지 않음 |

독립성·충분성의 세부 판정 절차는 v0.1의 제안을 유지한다. 위 3건 이외의 운영 세부안까지
새로 사용자 승인된 것으로 취급하지 않는다. 문서 충실성, 사실 상태 구분과 근거 추적,
근거 없는 원인·결과 생성 금지라는 기존 요구는 유지한다.

## 2. 독립 교훈의 정의와 분할·통합

독립 교훈은 문서 근거를 바탕으로 **어떤 조건에서 무엇을 판단하거나 실행해야 하는지**를
다른 교훈과 구별해 설명할 수 있는 하나의 배움이다. 적용 범위와 확실성은 근거 수준으로 제한한다.

v0.1에서 이어받은 판정 절차는 다음과 같다.

1. 문서의 관측 내용, 명시된 해석·가설, 제안·조치를 구분한다.
2. 후보별 적용 조건과 핵심 판단·행동을 적고, 근거 없는 내용은 채우지 않는다.
3. 하나를 제거해도 다른 후보에 별도의 판단·행동이 남고 각각 근거가 있으면 분리한다.
4. 적용 조건과 핵심 판단·행동이 같고 표현·근거 위치만 다르면 통합한다.
5. 같은 원칙의 절차·조건·예외·뒷받침 사실은 함께 둔다. 별도로 적용할 배움이 있을 때만 분리한다.

같은 사건이라는 이유로 서로 다른 교훈을 합치지 않는다. 반대로 후보 수를 늘리기 위해
한 교훈의 조건·절차를 잘게 나누지 않는다.

## 3. 공통 근거와 중복

**공통 근거 허용은 확정된 평가 기준이다.** 같은 블록을 사용해도 적용 조건이나 핵심
판단·행동이 다른 교훈이면 별도 카드로 인정할 수 있다. 다만 각 교훈에 대한 지지 여부를
각각 확인한다. 한 교훈을 지지하는 근거가 다른 교훈도 자동으로 지지하는 것은 아니다.

- 중복: 같은 적용 범위에서 실질적으로 같은 판단·행동이며, 합쳐도 독립적인 배움이 사라지지 않는다.
- 관련: 사건·근거·원인·목적을 공유하지만 서로 다른 판단·행동을 제공한다.

생성 프롬프트에 공통 근거를 재사용해 카드 개수를 늘리거나 최소 장수를 채우라는 지시를
넣지 않는다. 공통 근거 자체가 환각을 직접 늘린다는 결론을 내리지 않으며, 근거 없는 교훈을
덧붙이는 문제는 개별 주장 지지와 중복 판정으로 확인한다.

## 4. 근거 충분성과 정답표 포함

다음 요건은 v0.1의 판정안으로 유지한다.

- 출처 위치를 확인할 수 있다.
- 핵심 주장과 적용 범위를 원문 근거로 설명할 수 있다.
- 관측과 해석을 구분하며 추론의 연결 이유를 제시할 수 있다.
- 인과관계·효과·일반화의 강도가 근거 수준을 넘지 않는다.

**성공 관측의 부재만으로 정답표에서 제외하지 않는다.** 실패 기록, 위험 분석, 설계 결정,
미해결 문제, 명시된 가설에서도 위 요건을 충족하는 독립 교훈을 정답표에 포함한다.
자료 전체를 자동으로 정답 카드로 인정하거나, 근거가 부족한 문장에 교훈을 만들어 붙이는
의미는 아니다. 관측된 실패와 성공 여부가 불명인 경우도 구분한다.

제안은 제안으로, 명시 가설은 가설로 유지한다. 예상 효과를 관측 결과로 바꾸거나
선택 사실을 효과의 입증으로 바꾸지 않는다. 원문에 없는 원인·결과는 보완하지 않는다.

- 보류: 출처·문맥·핵심 충돌 때문에 교훈의 내용이나 적용 범위를 정하기 어렵다.
- 생략: 독립적인 배움이 없거나, 교훈을 성립시키려면 근거 없는 사실·일반화를 추가해야 한다.

## 5. 정답표와 공개 정책의 분리

정답표의 채택은 **문서가 해당 교훈을 뒷받침한다는 평가 판단**이다.
Gate의 pass, DB의 active, 사용자에게 공개할 수 있다는 결정을 뜻하지 않는다.

성공 관측 없는 자료의 공개 정책은 유형별 환각 측정 후 정한다. 이번 결정으로 이를
일괄 공개하거나 영구 비공개로 확정하지 않는다. 현재 공개 로직과 DB 상태도 변경하지 않는다.

유형별 측정을 준비하기 위한 기록안은 다음과 같다. 실제 필드·분모·표본 수·공개 임계값은
후속 확정 대상이며 이번에 평가기나 스키마를 구현하지 않는다.

| 기록 대상 | 기록안과 주의 |
|---|---|
| 성공 관측 | 원문에 성공 관측 있음 / 없음 / 판단 불가를 구분하고 근거 위치를 기록. 입력에서 못 찾은 것만으로 문서 전체에 없다고 단정하지 않음 |
| 자료 성격 | 실패 관측, 설계 선택·이유, 위험 분석, 미해결 문제, 가설·제안 등의 유형. 중첩 가능하며 복수 표기를 허용하는 안 |
| 오류 | 근거 없는 주장, 원문과 불일치, 원인·효과 단정, 가설의 사실 승격 등을 구분하는 안 |
| 집계 | 유형별 분자·분모·표본 수와 판정 불확실성을 함께 기록. 유형이 겹칠 때 중복 집계 여부 명시 |

성공 관측 없는 유형의 환각 위험이 더 크다는 우려는 **검증할 가설**이다.
노출된 소수 사례만으로 유형별 환각률이나 인과 효과를 확정하지 않는다.
평가 범위는 제공 문서에 대한 충실성까지이며 문서 밖 사건의 진위를 검증하지 않는다.

## 6. 정답표와 경계 사례 기록

v0.1의 최소 기록안인 교훈 ID, 핵심 판단·행동, 적용·제외 범위, 출처와 원문 내용,
주장별 근거 상태, 추론 이유·불확실성, 채택/보류/생략 사유, 관련·중복 후보 및
분할·통합 이유를 유지한다. 유형별 측정에 필요한 5장의 구분도 함께 기록하도록 준비한다.

여기서 사실은 원문이 사실로 진술한 내용이며 외부 검증 완료를 뜻하지 않는다.
사람/판정자의 설명에 상태를 병기할 수 있지만 현재 코드의 FactStatus를 변경하는 지시는 아니다.

- 핵심 교훈의 의미가 어디에도 표현되지 않으면 누락이다. 문구 일치로 판정하지 않는다.
- 같은 교훈을 여러 카드가 반복하면 중복이다. 근거 ID 일치만으로 판정하지 않는다.
- 한 카드가 여러 독립 교훈을 담으면 의미 포함 여부와 카드 단위 위반을 별도로 기록한다.
- 정답표 자체의 보류·분할 이견은 이유와 허용 가능한 대안을 남기고 확정 판정과 구분한다.
- 이 기준으로 과거 실행을 자동 재채점하지 않는다. 평가 시 기준 버전을 명시한다.

## 7. 적용 전 확인과 남은 결정

- [ ] 독립 교훈을 사건 단위로 다시 합치거나 한 교훈을 개수 맞추기로 분할하지 않는가?
- [ ] 공통 근거가 각 교훈을 실제로 지지하며, 같은 판단·행동의 반복을 걸러내는가?
- [ ] 성공 관측 없는 자료도 충분한 근거가 있으면 정답표에 포함하는가?
- [ ] 가설·예상 효과를 확정 사실로 바꾸지 않는가?
- [ ] 정답표 채택과 Gate/DB 상태·공개 승인을 구분했는가?
- [ ] 유형별 집계의 분모·표본 수·경계 사례를 명시했는가?

남은 결정은 유형별 환각 측정의 구체적 정의·설계와 그 결과에 따른 공개 정책이다.
정답표 작성·프롬프트 정렬·재실행·공개 정책 적용은 이번 문서 개정에서 수행하지 않았다.
