# Lessons Learned 카드 평가 방법론 초안

이 평가는 실제 세계의 진실 여부가 아니라 **원문에 충실한 교훈을 추출했는지**를 평가한다. 원문의 사실·가설·추론·미확인·충돌 상태를 보존하며, 내용의 충실성과 ‘독립 교훈당 카드 1장’ 규칙 준수를 별도로 측정한다. 아래는 실행 전 절차안이며, 승인·시험 완료·관측된 일치도를 의미하지 않는다.

## 1. 평가 단위와 정답표 고정

**교훈 단위**는 다른 교훈과 독립적으로 수용하거나 기각할 수 있는 하나의 판단 또는 행동 원칙이다. 동일 사건에서 나온 교훈도 판단·행동이 독립적이면 분리한다. 동일 교훈의 설명, 예시, 조건 보충, 표현 차이는 별도 교훈으로 늘리지 않는다.

공통 근거가 여러 교훈을 각각 지지하면 재사용할 수 있다. 근거 재사용 자체는 교훈을 추가하는 이유가 되지 않는다. 성공 관측이 없어도 원문에 충분한 근거가 있는 교훈은 포함하되, 관측된 성과처럼 서술해서는 안 된다.

문서별 최초 정답표 **G₀**에는 다음을 기록하고 생성 출력 열람 전에 고정한다.

- 교훈 ID와 원자적 교훈 문장
- 적용 조건·범위와 핵심 판단 또는 행동
- 근거 위치 및 근거가 교훈을 지지하는 설명
- 사실·가설·추론·미확인·충돌 구분
- 성공 관측 유무와 근거 충분성 판정
- 같은 사건의 다른 교훈과 분리한 이유, 허용 가능한 표현·범위 차이

정답 교훈으로서의 충분성이 해결되지 않은 항목은 확정 교훈과 분리해 경계 목록에 남긴다. G₀의 확정 교훈 분모에는 포함하지 않는다. 이는 생성 후 **대응 여부가 미해결인 경우**와 구별한다.

## 2. 출력 비노출 판정자 사전 조율

최종 평가에 사용하지 않을 문서 2~3개를 조율용으로 선정한다. 판정자 두 명은 생성 출력을 보지 않고, 서로의 라벨도 보지 않은 상태에서 각각 교훈·근거·범위·인식 상태·충분성을 작성한다. 독립성이란 이 작성 단계에서 상대의 교훈 목록이나 분할 결정을 참고하지 않는 것을 뜻한다.

독립 작성본은 합의 전에 원본 그대로 보존한다. 이후 문서 위치와 의미를 기준으로 두 목록을 정렬하되, 억지로 일대일 대응시키지 않는다.

| 정렬 결과 | 확인할 내용 |
|---|---|
| 1:1 | 같은 교훈인지, 조건·범위·충분성 판단이 같은지 |
| 1:N 또는 N:1 | 한쪽이 분리하고 다른 쪽이 통합한 이유 |
| 대응 없음 | 누락인지, 교훈으로 볼 수 없는 내용인지, 근거 부족인지 |
| 경계 | 원문이나 기준만으로 판정하기 어려운 이유 |

분할 이견은 “각 교훈을 독립적으로 수용·기각할 수 있는가”와 “한 교훈의 조건·설명에 불과한가”를 중심으로 해결한다. 충분성 이견은 원문 근거와 교훈 사이에 추가 가정이 필요한지 확인한다. 해결되지 않으면 제3 판정자가 원문과 기준에 따라 결정하거나 경계로 유지한다.

작은 표본과 사후 정렬 목록에 kappa나 임의의 합격 임계값을 강제하지 않는다. 대신 다음을 보고한다.

- 판정자별 교훈 수
- 명확한 1:1 대응 수, 분할·통합 이견 묶음 수, 대응 없는 항목 수
- 1:1 대응 항목에서 충분성·범위·인식 상태가 일치한 수와 해당 비교 항목 수
- 주요 이견, 해결 근거, 기준 변경 사항

다음 단계로 진행하는 조건은 단순한 일치율이 아니다. **반복되는 원칙 이견이 해소되고, 판정자가 적용할 운영 기준이 마련되어야 한다.** 핵심 기준을 수정했다면 독립 라벨링을 다시 수행하며, 가능하면 새로운 조율 문서를 사용한다. 수정한 기준이 같은 종류의 이견을 해결하는지 확인한다.

기준이 정리되어도 특정 원문의 모호성 때문에 남는 개별 사례는 이유와 함께 경계로 보존할 수 있다. 이러한 사례와, 여러 문서에 반복될 원칙 이견을 구분한다. 후자가 남아 있으면 기준 수정과 재조율을 계속한다. 조율 문서는 최종 평가 표본에 재사용하지 않는다.

## 3. 생성 카드의 사후 판정

생성 후 판정자는 **카드와 원문을 읽어야 한다**. 이 단계는 출력 비노출 평가가 아니다. 대신 시스템 이름·버전·기존 점수 등 출처 정보를 가리고, 모든 시스템에 같은 판정 절차를 적용한다.

각 카드에는 두 축의 판정을 부여한다.

1. **내용 타당성: 타당 / 부당 / 경계**
   원문과 확정된 기준으로 판단한다. 중요한 주장과 인식 상태가 모두 지지되면 타당, 중요한 주장에 근거가 없거나 원문과 충돌하면 부당, 합리적인 해석이 갈리고 해소되지 않으면 경계다.
2. **교훈 구성: 교훈 없음 / 독립 교훈 1개 / 독립 교훈 여러 개 / 판정 경계**
   여러 교훈을 정확하게 담은 카드도 내용상 타당할 수 있지만, 카드당 교훈 1개 규칙에는 위반한다. 같은 교훈을 반복한 카드도 내용상 타당할 수 있다.

**카드 전체의 내용 타당성과 특정 교훈의 포착 여부는 별도로 판정한다.** 예를 들어 한 교훈은 정확하게 설명했지만 별개의 성과 수치를 지어낸 카드는 내용상 부당하면서도 해당 교훈을 완전히 포착할 수 있다. 다만 오류나 모순이 그 교훈의 핵심 주장·필수 조건·인식 상태 자체를 훼손하면 완전 포착을 인정하지 않는다.

정답표와의 대응 여부만으로 내용 타당성을 결정하지 않는다. 정답표 밖 카드도 원문이 지지하면 타당할 수 있다.

## 4. 카드–교훈 대응 규칙

카드와 G₀의 교훈 사이에 **완전 일치 / 부분 일치 / 불일치 / 경계** 관계를 기록한다. 표현 유사성보다 교훈의 판단·행동, 적용 조건·범위, 인식 상태를 비교한다.

**완전 일치는 해당 교훈의 핵심 주장, 필수 조건, 사실·가설·추론 등의 인식 상태가 모두 원문으로 지지될 때만 인정한다.** 필수 조건은 출력에 맞춰 사후 변경하지 않는다.

| 대응 | 처리 |
|---|---|
| 카드 1장 → 교훈 1개 | 핵심 주장·필수 조건·인식 상태가 충족되면 완전 일치 |
| 카드 1장 → 교훈 여러 개 | 각 교훈의 내용 포착은 각각 인정하고, 카드 합침 위반은 별도로 기록 |
| 카드 여러 장 → 교훈 1개 | 완전한 반복과 상호 보완적인 분절을 구분 |
| 부분 일치 | 중요한 조건·행동 등이 빠졌지만 일부 교훈은 지지되는 경우 |
| 범위 차이 | 원문보다 넓은 일반화는 근거를 확인하고, 좁은 범위는 핵심 교훈을 충족하는지 판단 |

원문이 특정 조건에서만 지지하는 주장을 무조건적인 원칙으로 넓혔다면 완전 일치로 인정하지 않는다. 더 좁은 범위라도 독립적으로 충분히 지지되는 교훈이면 정답표 밖 타당 교훈일 수 있다.

여러 카드가 상호 보완적으로 하나의 교훈을 완성하는 경우에는, **원문에 없는 연결이나 추가 추론 없이** 합쳐서 필요한 내용을 충족할 때만 ‘분절 후 완전 포착’으로 인정한다. 카드 한 장에서 완전히 포착한 경우와 구분해 기록한다.

같은 교훈을 여러 카드가 찾아도 재현율에는 한 번만 반영한다.

## 5. 교훈별 최종 집계 상태

G₀의 각 확정 교훈은 다음 네 상태 중 하나에만 속한다. 카드별 대응 판정을 교훈별로 모은 뒤 집계한다.

| 상태 | 정의 |
|---|---|
| **완전** | 적어도 한 카드 또는 인정된 상호 보완 카드 묶음이 완전히 포착한다고 확정됨 |
| **부분만** | 완전 포착은 없고, 확정된 부분 일치가 있으며, 이 집계 상태를 바꿀 미해결 대응이 없음 |
| **확정 누락** | 완전·부분 일치가 모두 없고, 이 집계 상태를 바꿀 미해결 대응도 없음 |
| **미해결 경계** | 완전 포착이 확정되지 않았으며, 미해결 대응에 따라 완전·부분만·확정 누락 중 최종 상태가 달라질 수 있음 |

이미 완전 포착이 확정되었다면 다른 경계 대응이 있어도 **완전**이다. 반면 확정된 부분 일치와 경계 대응이 함께 있고, 경계 대응이 완전 포착으로 인정될 가능성이 남아 있다면 **미해결 경계**로 집계한다. 이때 ‘확정 부분 일치 있음’이라는 보조 표식은 보존한다.

경계 대응만 남은 교훈은 **확정 누락에 포함하지 않는다**. 경계가 완전 포착 가능성과 무관하더라도 부분·누락 구분을 바꿀 수 있다면 미해결 경계로 남긴다.

따라서 다음이 성립한다.

**전체 확정 교훈 수 N = 완전 F + 부분만 P + 확정 누락 M + 미해결 경계 B**

## 6. 권장 지표와 분모

카드 단위와 교훈 단위 지표를 구분해 함께 보고한다. 하나의 종합 점수로 합치지 않는 것을 권장한다.

| 지표 | 분자 | 분모 |
|---|---|---|
| **확정 포착 재현율** | G₀에서 완전 상태인 고유 교훈 수 F | G₀의 확정 교훈 수 N |
| **단일 카드 완전 포착률** | G₀ 중 적어도 한 카드가 단독으로 완전히 포착한다고 확정된 고유 교훈 수 | N |
| **부분만 비율** | 부분만 상태인 교훈 수 P | N |
| **확정 누락률** | 확정 누락 상태인 교훈 수 M | N |
| **미해결 경계율** | 미해결 경계 상태인 교훈 수 B | N |
| **카드 타당률** | 타당 카드 수 | 타당＋부당 카드 수 |
| **카드 합침률** | 독립 교훈을 2개 이상 담은 카드 수 | 교훈 개수를 확정한 카드 수 |
| **분절 포착 비율** | 여러 카드의 결합으로만 완전히 포착되었다고 확정된 고유 교훈 수 | 완전 상태인 고유 교훈 수 F |

확정 포착 재현율 F/N은 **현재 확정된 완전 포착의 비율**이다. 경계가 남았다면 이를 경계 해소 후의 단일 최종 재현율처럼 제시하지 않는다.

미해결 경계 중 완전 포착으로 결정될 가능성이 남은 교훈 수를 **Bꜰ**라고 하면, 경계 해소 후 재현율 범위는 다음과 같다.

**F/N ≤ 최종 재현율 ≤ (F＋Bꜰ)/N**

모든 경계 교훈이 완전 포착 후보인 것은 아니므로 상한에 B 전체를 자동으로 더하지 않는다. B=0이면 F/N이 최종 확정 재현율이다. 단일 카드 완전 포착률에도 해당 판정의 경계가 있다면 같은 방식으로 확정값과 가능한 범위를 구분한다.

카드 타당률은 **내용 타당성 지표**이며 중복·합침 규칙 준수와 별개다. 타당 V, 부당 I, 경계 U인 경우 판정 완료 카드의 타당률은 V/(V＋I)이며, 전체 카드 기준 경계 해소 범위는 **V/(V＋I＋U)부터 (V＋U)/(V＋I＋U)**까지다. 경계 수와 비율을 함께 제시한다.

교훈 개수 경계 카드 수, 교훈이 없는 카드 수, 분절 인정 여부가 경계인 교훈 수도 별도로 보고한다. 부분 일치에 임의의 0.5점을 부여하지 않는다.

### 중복의 집계

**완전 반복 대응률**은 사용하는 정답 집합 버전을 명시한다. 최초 평가는 G₀를 사용한다.

G₀의 교훈 g에 단독으로 완전 일치하는 카드 수를 n_g라 하면:

- 분자: 각 g에 대한 **max(0, n_g−1)**의 합
- 분모: 각 g에 대한 **n_g**의 합

이는 **완전 일치 카드–교훈 대응 관계 단위**의 중복률이며 카드 수의 비율이 아니다. 한 카드가 여러 교훈에 완전 일치하면 각 대응을 기록하고, 합침 위반은 따로 센다. 상호 보완 카드 묶음과 부분 카드의 내용 반복은 이 지표에 섞지 않고 별도 표식으로 남긴다. 미해결 완전 일치 후보도 확정 대응 수에 섞지 않는다.

G₀ 밖 타당 카드끼리도 발견 목록에서 의미상 같은 교훈의 중복 묶음을 만들고, 각 묶음의 카드 수와 최초 1개를 제외한 초과 수를 남긴다. 확장 정답표로 반복 대응률을 산출한다면 **G₀∪G₊의 해당 버전**을 명시하고 G₀ 결과와 구분한다.

### 0분모와 결과 합산

분모가 0이면 **해당 없음(N/A)**으로 표시한다. 정답 교훈이 없는 문서의 재현율이나 카드가 없는 실행의 카드 타당률을 0% 또는 100%로 처리하지 않는다.

문서별 분모와 전체 합산 분모를 공개한다. 문서 평균을 추가한다면 전체 합산 결과와 별도 지표로 명시한다. 경계 제외 점수만으로 시스템을 비교하지 않는다.

## 7. 정답표 밖 타당 교훈과 공정한 비교

G₀에 대응하지 않는 카드는 별도 발견 목록에 넣고 타당·부당·경계로 판정한다. 타당 판정에는 원문 위치, 독립 교훈인 이유, 충분성 근거가 필요하다. 생성된 카드가 그럴듯하다는 이유로 추가하지 않는다.

사후 타당 발견 **G₊**는 G₀를 덮어쓰지 않는다.

- 최초 결과는 G₀ 기준으로 유지한다. 정답표 밖이라는 이유만으로 카드 타당성을 낮추지 않는다.
- 비교 대상 시스템 전체의 발견을 출처를 가린 상태로 모아 중복·분할·범위를 정리한다.
- 확정된 공통 확장표 G₀∪G₊로 모든 시스템의 기존 출력을 다시 대응시킨 결과를 보조 결과로 제시한다.
- 시스템마다 다른 정답표를 적용하거나, 자기 출력에서 발견한 교훈만 자기 점수에 추가하지 않는다.

확장표도 모든 가능한 교훈을 망라했다고 보장할 수 없다. 따라서 확장 결과는 사후 보완 평가로 표시한다.

## 8. 버전 관리와 재시험 조건

합의 전 독립 판정, 정렬표, 불일치 사유, 최종 판정과 변경 이력을 보존한다. 기준·G₀·G₊·대응 결과에는 각각 버전을 부여한다.

단순 ID 수정이나 명백한 기록 오류는 영향을 받는 항목을 모든 시스템에 동일하게 재채점한다. 교훈 분할·충분성·범위·완전 일치 기준이 바뀌면 영향 범위 전체를 재판정하고 관련 지표를 다시 계산한다. 변경 전 결과도 보존한다.

출력을 본 뒤 프롬프트나 시스템을 수정했거나 평가 기준을 그 출력에 맞춰 조정했다면, 기존 문서에서의 재실행은 개발 결과로 취급한다. 확증 비교에는 새 홀드아웃을 사용한다. 사후 G₊를 학습·튜닝·프롬프트 개선에 사용한 경우도 같다.

## 9. 가상 판정 예시

**다음은 절차 설명용 예시이며 실제 관측이나 정답표가 아니다.**

1. **분리와 공통 근거:** 배치 재실행 중 중복 적재와 실패 구간 식별 어려움이 기록되어 있다. “적재를 멱등하게 설계한다”와 “배치별 처리 이력을 남긴다”가 각각 근거로 지지된다면 독립 교훈 두 개로 나눌 수 있다. 같은 장애 기록을 공통 근거로 사용할 수 있다. 두 교훈을 카드 한 장에 담았다면 각각의 포착은 인정하되 합침 위반을 기록한다.

2. **통합과 분절:** “체크포인트를 저장한다”와 “저장한 체크포인트부터 재시작한다”가 하나의 복구 원칙을 이루는 문서라면, 두 문장을 자동으로 별도 교훈으로 만들지 않는다. 두 카드가 함께 필수 조건을 충족하면 분절 후 완전 포착으로 기록할 수 있다. 각 카드가 단독으로 같은 원칙을 완전히 설명한다면 반복 대응이다.

3. **성공 관측 없음과 근거 부족:** 문서가 API 제한으로 인한 반복 실패와 재시도 간격 필요성을 뒷받침한다면, 성공 실험 없이도 조건부 교훈을 포함할 수 있다. 그러나 “특정 간격으로 처리량이 30% 향상되었다”는 관측이 없다면 그 성과 주장은 부당하다. 이 오류가 별개의 주장이라면 카드 전체는 부당하면서도 조건부 교훈의 포착은 인정될 수 있다.

4. **정답표 밖 타당 카드:** G₀에는 배치 멱등성만 있지만 원문에 입력 스키마 변경을 사전 검증해야 한다는 충분한 근거도 있다면, 생성된 스키마 검증 교훈은 G₊ 후보로 판정한다. 같은 교훈을 여러 카드가 표현하면 발견 목록에서 중복 묶음과 초과 수를 남긴다. G₀의 분모는 유지하고, 카드 타당성과 공통 확장표 평가에 반영한다.

성공 관측 없는 교훈의 공개 정책은 이 절차에서 미리 확정하지 않는다. 성공 관측 유무와 교훈 유형별로 부당 카드의 양상·비율·분모를 확인한 뒤 결정한다.
